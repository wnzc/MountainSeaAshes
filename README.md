# 山海余烬 · 镜水涧 Demo

《山海余烬》手机竖屏 **2D 元素连锁塔防** 首关可玩 Demo。

依据：

- 《山海余烬_开发基准设计文档_GDD_v1.0》
- 《山海余烬_Godot首关Demo开发文档_v1.0》

本仓库用 **HTML5 Canvas** 实现了技术文档中的镜水涧 MVP 规格，数据驱动架构与 Godot Resource 设计一一对应，便于后续迁移到 Godot 4.x。

## 运行

用浏览器直接打开 `index.html`，或在本目录执行：

```bash
python3 -m http.server 8765
# 访问 http://localhost:8765
```

竖屏体验最佳；桌面浏览器会以 9:16 居中显示。

## 玩法（30 秒理解）

1. 放灵兽 → 自动攻击沿路线前进的墨蚀异兽  
2. 不同元素附着在同一敌人 / 环境上会触发 **双元素反应**  
3. 短时间内连续反应会升 **2 / 3 / 4 连**，4 连触发「山海异象」  
4. 相邻不同元素灵兽产生 **共鸣**，延长元素状态  
5. 蚀兽抵达底部会伤灵种；守住 8 波（含 Boss 蚀山君）即胜利  

### 操作

| 操作 | 效果 |
|------|------|
| 点击底部灵兽卡 | 选中待放置 |
| 点击空塔位 | 放置 |
| 点击已放灵兽 | 查看属性 / 升级 / 撤回 |
| ×1 / ×2 | 战斗倍速 |
| Ⅱ | 暂停 |

### 首发五灵

| 灵兽 | 元素 | 定位 |
|------|------|------|
| 赤羽 | 炎 | 范围燃烧 |
| 沧璃 | 沧 | 铺水潮湿 |
| 雷角 | 霆 | 湿目标弹射 |
| 风狸 | 岚 | 扩散环境 |
| 霜狐 | 霜 | 减速冻结 |

### P0 六反应

- 沧 + 霆 = **导电**（弹射）
- 沧 + 霜 = **冻结**（冰面）
- 炎 + 岚 = **火旋风**（火场）
- 炎 + 沧 = **蒸汽**
- 炎 + 霜 = **融裂**（爆发 + 蒸汽）
- 霆 + 岚 = **雷暴**（持续落雷）

推荐 4 连：沧（水迹）→ 霜（冻结）→ 炎（融裂/蒸汽）→ 岚（蒸汽旋涡）→ 霆（雷暴）

## 地图：镜水涧

- 单 S 路线，入口右上 → 灵种下方  
- **10 个固定塔位**，含三向 / 四向核心位  
- 中部 **天然浅水** + 下方水潭，可参与反应  
- 数值可调：全部在 `js/data.js`  

## 架构（对应 Godot 文档）

| HTML | Godot |
|------|-------|
| `js/data.js` | `resources/*.tres`（Spirit/Enemy/Reaction/Wave/Map） |
| `js/eventBus.js` | `autoload/event_bus.gd` |
| `js/engine.js` BattleManager / ReactionSystem / ChainSystem | `scripts/battle/*` |
| `js/main.js` HUD | `scenes/ui/*` |

新增灵兽 / 怪物 / 反应：只改 `js/data.js` 配置，不必改核心循环。

## 目录

```
index.html

js/

  eventBus.js   # 事件总线
  engine.js     # 战斗、反应、连锁、环境、渲染
  main.js       # HUD 与输入
```

## 验收对照（技术文档 §26）

- 怪物沿路线稳定到终点，突破扣灵种生命  
- 仅空塔位可放置；邻接共鸣正确  
- 金币：放置 / 升级 / 击杀收支  
- 元素附着、反应顺序无关（A+B = B+A）  
- 2/3/4 连计时与「山海异象」  
- 环境：天然水域 / 冰面 / 蒸汽 / 火场  
- 8 波 + Boss，胜负结算
